# RoboComm — лендинг

Статический сайт без сборки: открывается двойным кликом по `index.html`, деплоится на Netlify перетаскиванием папки.

## Структура и куда класть статику

```
robocomm-site/
├── index.html                 ← вся разметка. Каждая секция помечена комментарием [НАЗВАНИЕ]
├── assets/
│   ├── css/style.css          ← стили; в начале — оглавление [1]–[11], палитра в [1]
│   ├── js/main.js             ← меню, анимации, блик стекла
│   ├── img/
│   │   ├── rc-logo.svg        ← ЛОГОТИП (замените своим; если png — поправьте пути в index.html)
│   │   ├── og-cover.jpg       ← картинка для превью ссылки, 1200×630
│   │   ├── team/founder.jpg   ← ФОТО основателя (раскомментируйте <img> в секции [05 О КЛУБЕ])
│   │   └── projects/          ← фото проектов (по желанию)
│   └── video/
│       ├── logo-build.webm    ← ВИДЕО в hero (8 сек, loop)
│       └── logo-build.mp4     ← запасной формат для Safari/iOS
```

## Секции в index.html

| Метка в коде | id | Что там |
|---|---|---|
| [HEAD] | — | title, описание, og-превью, шрифты |
| [BACKGROUND] | — | фон-«капли» и SVG-фильтр стекла |
| [HEADER / NAV] | `#top` | шапка и меню |
| [HERO] | `#hero` | первый экран + видео логотипа |
| [01 · НАПРАВЛЕНИЯ] | `#directions` | 4 ступени |
| [02 · ПРОЕКТЫ] | `#projects` | 3 проекта |
| [03 · СОБЫТИЯ] | `#events` | расписание (даты — заглушки) |
| [04 · ПУТЬ / МЕНТОР] | `#mentor` | путь участника → ментор |
| [05 · О КЛУБЕ] | `#about` | текст, основатель, слоты менторов |
| [06 · КАК УСТРОЕН КЛУБ] | `#how` | 3 колонки + цитаты (цитаты — заглушки) |
| [JOIN] | `#join` | призыв к действию, ссылки на бот и соцсети |
| [FOOTER] | — | подвал |

## Что нужно заменить на реальное
- Тексты 4 «ступеней», даты/места событий и цитаты участников — черновики.
- Логотип, фото основателя, видео, `og-cover.jpg`.

## Стекло
Эффект задаётся классом `.glass` в `style.css` раздел [4]. Сила размытия — `--glass-blur`, прозрачность — `--glass-bg`.
